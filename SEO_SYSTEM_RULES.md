# SEO System Rules

Use these rules any time this project is adapted for a new client, service page, city page, or landing page.

The goal is simple:

- clear search intent
- local relevance
- strong click-through potential
- easy reuse across multiple client projects

## Core SEO Principles

- One primary page intent per page
- One main keyword theme per page
- One clear offer per page
- One primary call to action per page

Do not try to rank one page for everything.

## Page Title Rules

- Keep titles clear and direct
- Put the primary service first
- Add the city or service area when relevant
- Keep titles readable, not stuffed

Good pattern:

`Primary Service | City | Brand Name`

Example:

`Lead Capture Systems | Dallas, TX | Randy Urizar Production`

## Meta Description Rules

- Write for clicks, not just keywords
- Mention the offer, target audience, and action
- Keep it concise and natural

Good pattern:

`Custom lead capture systems for local businesses in Dallas, TX. Get a clean landing page, simple form flow, and faster lead notifications.`

## Heading Rules

- One `h1` per page
- `h1` should match the core offer
- Use `h2` elements for major sections
- Use `h3` elements inside cards, steps, and grouped content
- Keep headings benefit-driven and easy to scan

## Local SEO Rules

For city or regional pages:

- mention the city naturally in title, meta description, `h1`, and body copy
- mention service area in contact/footer content
- keep location references real and specific
- do not mass-stuff city names unnaturally

## Content Rules

- Write for real buyers first
- Keep copy concrete and easy to understand
- Focus on outcomes, speed, trust, and clarity
- Use short sections with strong subheads
- Include proof, process, and CTA language

## Internal Link Rules

Use internal links to connect:

- services
- industries
- city pages
- FAQ pages
- case studies
- contact section

Anchor text should be descriptive, not generic.

## Image SEO Rules

For any image added to `assets/images/`:

- use descriptive filenames
- include accurate `alt` text
- avoid generic names like `image1.jpg`
- prefer compressed images for faster load times

Good filename pattern:

`dallas-lead-capture-dashboard.jpg`

## Social Sharing Rules

Each production page should eventually support:

- page title
- meta description
- Open Graph title
- Open Graph description
- Open Graph image

Recommended Open Graph image location:

`assets/images/og/`

## Reusable Page Checklist

Before shipping a new client page, confirm:

1. The title is specific to the service and location.
2. The meta description matches the actual offer.
3. The page has one clear `h1`.
4. The CTA is visible above the fold and near the bottom.
5. The copy includes trust, process, and action.
6. Images have descriptive names and alt text.
7. Internal links point to the right service, city, or contact pages.
