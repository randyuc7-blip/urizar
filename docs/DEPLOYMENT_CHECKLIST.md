# Deployment Checklist

This project is designed to stay easy to ship.

## GitHub + Netlify Flow

1. Push the project to a GitHub repository.
2. Connect the repository to Netlify.
3. Set the publish directory to the project root if needed.
4. Deploy the site.
5. Submit a test lead through the form.
6. Confirm the Netlify form captured the submission.

## Pre-Launch Checks

- all client copy is updated
- contact info is correct
- images load correctly
- form status messages work
- footer links are intentional
- mobile layout looks clean
- title and meta description are correct

## Post-Launch Checks

- test the live form
- verify notification or form review process
- check the site on mobile
- confirm the domain is connected if applicable

## Keep It Simple

If the project can stay static, keep it static.

Only add backend logic, Netlify functions, or external integrations when the client actually needs lead processing beyond basic form capture.
