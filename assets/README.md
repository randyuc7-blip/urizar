# Assets Folder

This folder stores reusable client assets.

## Folder Rules

- `images/`: photos, gallery images, Open Graph images, thumbnails
- `icons/`: logos, favicons, SVG marks, UI icons
- `files/`: PDFs, brochures, lead magnets, downloads

Keep filenames descriptive so they are easy to find and reuse.

Good example:

`dallas-roofing-hero.jpg`

Bad example:

`image-final-new-2.jpg`
